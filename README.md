# zed-themes
My Zed IDE theme collection

# to install
Run the install script:
```
./install.sh          # copy the themes
./install.sh --link   # or symlink them, so `git pull` keeps them up to date
```

It puts the theme files into
```
~/.config/zed/themes/
```
(or `$XDG_CONFIG_HOME/zed/themes/` if `XDG_CONFIG_HOME` is set).
